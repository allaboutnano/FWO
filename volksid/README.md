# volksid – offener Ausweis (Spezifikation)

Ziel: Nachweis, dass eine Stimme von einem **berechtigten Menschen** kommt und **genau einmal** zählt – ohne offenzulegen, wer wie gestimmt hat. Der Ausweis gehört den Bürgern, keiner Behörde.

Zuerst zu schreiben: Anforderungen, Bedrohungsmodell, Abgrenzung zu staatlichen Ausweisen (EU-Wallet), Kandidaten-Standards (W3C DID und Verifiable Credentials, Zero-Knowledge-Nachweise).

Ungelöst (Kernfrage): Wie wird ein Mensch einmalig bestätigt, ohne dass eine einzelne Stelle das Monopol darüber hat?

Hier gehören nur Spezifikation und Code hin, **nie** echte Personendaten.
