# datensafe – nutzerkontrollierte Ablage (Spezifikation)

Ende-zu-Ende-verschlüsselte Ablage für Schlüssel, Nachweise (VolksID) und eigene Daten. Schlüssel liegen nur beim Nutzer. Der Safe läuft auf den Geräten der Nutzer; das Repo enthält nur Code und Spezifikation, nie Inhalte.

Zuerst zu klären: Bedrohungsmodell, Schlüsselverlust und Wiederherstellung (Buch: „Was, wenn ich den Zugang verliere?"), Vererbung, Synchronisation zwischen Geräten.
