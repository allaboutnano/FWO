Lösungen

Das bestehende System kann nicht reformiert werden. Es kann nur ersetzt werden.

Das Konzept zur Freien Welt Ordnung setzt dem Bestehenden ein Gegenmodell entgegen. Es soll das alte System ablösen, überflüssig machen.

Sei wie Wasser. Durchdringe das System. Mach das alte überflüssig.

Der erste Schritt

Geld von unten – nicht von oben. Wenn wir den Machtfaktor Geldsystem auflösen, ist das der Beginn unserer Freiheit. Wie das mit Nano (Ӿ) heute schon geht, steht unter Pfeiler 1: Freies Geldsystem.
