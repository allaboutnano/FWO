# Offene Fragen (aus dem Buch übernommen, nicht stillschweigend lösen)

## ghaSPI (Kap. 8.8)
- [ ] Rückfluss aus exportierten Rohstoffen: Betrag, SPI-Satz je Rohstoff
- [ ] Wirkung des Steuerwegfalls auf Preise und Nettoeinkommen
- [ ] Verschiebung des gesamten Preisgefüges
- [ ] Verteilung des Verbrauchs *innerhalb* der Länder (belegt nur weltweit)
- [ ] Investitionsverbrauch je Vermögensgruppe
- [ ] Übergangsphase: Sparguthaben, Kredite, Hypotheken, Renten, Versicherungen
- [ ] GOV (Höhe) und SPI-Sätze: Entscheidung der Basisdemokratie

## Volksversammlung (Kap. 6.9)
- [ ] Rechtsstellung (Versammlungsrecht, Datenschutz, je Land)
- [ ] Moderation: wer schreibt die Sortier-Automatik und wonach sortiert sie?
- [ ] Praxisregeln: Aufgaben, Fristen, Mindestbeteiligung, Obergrenze übertragener Stimmen, Skalierung, Pilot-Schwellen

## Basisdemokratie (Kap. 7.8)
- [ ] Verbindlichkeit gegenüber dem bestehenden Staat
- [ ] Identität (VolksID, Datensafe)
- [ ] Ausdauer: dauerhafte Beteiligung

## Technik
- [ ] Welche Chain/welches Protokoll für Abstimmungen (siehe ADR 0002)
- [ ] Sybil-Resistenz ohne Behörden-Monopol
